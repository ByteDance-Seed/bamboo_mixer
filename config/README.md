# Configs for different stages

The entire framework includes the following stages:

1. Training the single molecule predictor.
2. Training the formula predictor, including two substages: Pretraining with MD simulation data, and finetuning with experimental conductivity data.
3. Training the generative design model using synthetic data generated by the trained formula predictor, including two substages: training the diffusion module and training the decoder.

## Data configs

| Stage                            | Train                                                                      | Inference                               |
| -------------------------------- | -------------------------------------------------------------------------- | --------------------------------------- |
| Prediction: Single Molecule      | train_predictor_mono_config.yaml                                           | inference_predictor_mono_config.yaml    |
| Prediction: Formula              | train_predictor_pretrain_config.yaml, train_predictor_finetune_config.yaml | inference_predictor_formula_config.yaml |
| Design: Formula data preparation | synthetic_preprocess_config.yaml, synthetic_embedding_config               | NA                                      |
| Design: Formula                  | train_generator_diffusion_decoder_config.yaml                              | NA                                      |

Note:
During the `Design: Formula data preparation` stage, first use the `synthetic_preprocess_config.yaml` to convert the synthetic_data.json to pkl file, then use the `embedding.py` file to generate the embedding.h5 file, solv_embs.pt and salt_embs.pt files. Finally during the `Design: Formula` stage, use the `train_generator_diffusion_decoder_config.yaml` to load the synthetic data, embedding.5, solv_embs.pt and salt_embs.pt files together to train the diffusion module and decoder.
